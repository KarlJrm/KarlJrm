### CampusBites

**UI/UX · Mobile Application**

A mobile food ordering system designed for **PSU ACC faculty and staff**, focusing on a simple ordering experience from browsing to checkout.

### Fixly

**UI/UX · Product Design**

A service platform concept connecting customers with service providers through a streamlined **booking, estimation, and service process**.

### LifeArchive

**UI/UX · Product Concept**

A personal digital space designed to help people **preserve, organize, and revisit** memories, achievements, projects, relationships, and important moments.

### Finance Tracker

**Front-End Development · Currently Building**

A personal finance management web application I'm building as a hands-on project to strengthen my front-end development skills.



### Activity Tracker

**Python · Desktop Application · UI/UX**

A lightweight Windows desktop application that tracks keyboard activity, mouse activity, active and idle time, daily history, and activity trends.

The project combines **event-driven programming, SQLite database design, data visualization, and interface design** into a single desktop application.
